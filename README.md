# 💾 Save Slots — расширение для TurboWarp

Расширение для [TurboWarp](https://turbowarp.org/) (и других Scratch-совместимых редакторов), которое добавляет **систему сохранений в браузере**. Позволяет проекту запоминать прогресс между сессиями — без серверов, аккаунтов и API.

Идеально подходит для игр с прогрессом, редакторов, трекеров и обучающих проектов.

---

## ✨ Возможности

### Ручные слоты (работают в песочнице)
- 💾 Сохранить текст в слот
- 📂 Загрузить текст из слота
- ❓ Проверить, существует ли слот
- 🗑️ Удалить слот
- 📋 Получить список всех слотов
- 🧹 Очистить все слоты

### Автоматические слоты (нужен режим без песочницы)
- 💾 **Сохранить все переменные проекта одной командой**
- 📂 Загрузить все переменные из слота
- ℹ️ Посмотреть информацию о слоте (тип + дата сохранения)

Данные хранятся в `localStorage` браузера. Они переживают перезагрузку страницы, закрытие вкладки и выключение компьютера (пока пользователь не очистит данные браузера).

---

## 🚀 Установка

### Способ 1: Загрузка файла вручную

1. Скачайте файл `save-slots.js` из этого репозитория.
2. Откройте [TurboWarp Editor](https://turbowarp.org/editor).
3. Внизу слева нажмите **«Добавить расширение»** → **«Custom Extension»** → **«Load from file»**.
4. Выберите скачанный файл.
5. **Важно:** для блоков «все переменные» включите галочку **«Run extension without sandbox»** при загрузке.
